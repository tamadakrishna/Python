# Conditions

Conditions allow your program to make decisions based on whether something is True or False.

Python uses:

    - if

    - elif

    - else

    - match

Conditions are based on boolean expressions (True / False).


## Basic if Statement

Executes code only if the condition is true


## if – else Statement

Executes one block if true, another if false.



## if – elif – else Statement

Used when you have multiple conditions.



## Nested if Statements

An if inside another if.



## Shorthand if (Ternary Operator)

Used for simple conditions.



## match Statement

    - match is used for multi-branch decision making

    - It compares a value against patterns

    - Cleaner than long if–elif–else chains

    - Available in Python 3.10+ only
