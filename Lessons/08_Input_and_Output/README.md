# User Input in Python

User input allows a program to take data from the user at runtime instead of using fixed values.

Python uses the input() function.

Example: input("message")


- The message is optional

- input() always returns a string

# User Output in Python

User output means displaying information to the user.

Python mainly uses:

print() function

formatted output (f-strings, .format())
