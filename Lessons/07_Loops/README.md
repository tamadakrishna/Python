# Loops

Loops are used to repeat a block of code multiple times without writing it again and again.

Python has two main loops:

- for loop

- while loop


Python also uses:

- break

- continue

- pass


## Nested Loops

A loop inside another loop.


## Loops using Range(start, stop, step)

- Range() is used to generate a sequence of numbers

- Commonly used with for loops

- It does not create a list, it creates a range object

| Parameter | Description                 |
| --------- | --------------------------- |
| `start`   | Starting number (inclusive) |
| `stop`    | Ending number (exclusive)   |
| `step`    | Increment / decrement value |






## Looping with else
In Python, a loop’s else block:

- Runs ONLY if the loop finishes normally
- Does NOT run if the loop is terminated by break
