# Data Structures

Data structures are ways to organize and store data so that it can be accessed and modified efficiently.

Python has these main built-in data structures

1. List – Ordered, mutable collection
2. Tuple – Ordered, immutable collection
3. Set – Unordered collection of unique items
4. Dictionary – Key-value pairs

## 1. List
- Ordered → keeps the order of elements
- Mutable → can add, remove, or modify items
- Can contain mixed data types


## 2. Tuple
- Ordered → keeps the order
- Immutable → cannot be changed after creation
- Useful for fixed collections

## 3. Set
- Unordered → no indexing
- Unique elements only
- Mutable → can add/remove items

## 4. Dictionary
- Key-value pairs
- Mutable
- Unordered (Python ≥3.7 maintains insertion order)
