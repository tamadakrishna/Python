# Module

A module in Python is simply a file that contains Python code—such as functions, variables, or classes—that you can reuse in other programs. Modules help keep programs organized, clean, and reusable.


## Usage

    - Break large programs into smaller, manageable parts
    - Reuse code without rewriting it
    - Improve readability and maintenance


## Types of Modules
    - Built-in Modules
        - Ex: math, random, sys, datetime
    - User-defined Modules
        - User created modules
    - External (Third-party) Modules
        - Ex: Pandas, Numpy


## PYCACHE
__pycache__ is a folder automatically created by Python when you import a module.

It stores compiled versions of your Python files in bytecode format (.pyc files).
